# Introduction

## 1. 研究背景：从专用模型到可适配的材料基础模型

原子尺度材料建模包含一组相互联系、但变换规律不同的任务：总能量、形成能和带隙是标量；原子力是随坐标系旋转的向量，并可由总能量对坐标的负梯度得到；介电、弹性和压电响应是具有确定阶数与内禀对称性的张量；光学、电学和声子响应还可能随频率连续变化。密度泛函理论（density functional theory, DFT）及其线性响应方法能够提供这些标签，但计算成本限制了可覆盖的材料、构型和频率范围。机器学习模型试图学习从元素种类、原子坐标和周期性晶胞到多类物理量的映射，以较低成本支持结构弛豫、分子动力学、材料筛选和响应性质预测。其中，机器学习原子间势（machine-learning interatomic potentials, MLIPs）是物理约束最强、数据和基础模型最成熟的起点：模型逼近势能面，并从同一标量能量导出保守力。

几何等变网络显著提高了原子势和材料性质预测的精度与数据效率。与仅使用旋转不变量的模型不同，NequIP、Allegro 和 MACE 等模型在隐藏层中保留标量、向量及更高阶张量特征，使内部表示在旋转、反射和平移下按确定规律变换，而输出根据目标性质选择相应的不可约表示。NequIP 证明了严格的 \(E(3)\) 等变消息传递可以在有限标注数据下获得高精度势能与力；Allegro 将等变表示与严格局域的计算结构结合，以支持大规模并行模拟；MACE 则把高阶原子簇展开与等变消息传递结合，在较少消息传递层数下表达高体阶相互作用 [1–3]。这些工作说明，物理对称性不仅是输出正确性的约束，也是提高样本效率的重要归纳偏置，而且同一等变骨干原则上可以连接标量、向量、张量或谱函数等不同输出头。

在此基础上，材料原子势正在从“一个体系训练一个模型”转向大规模预训练。CHGNet、MACE-MP 和 MatterSim 等模型利用覆盖广泛元素、结构和热力学条件的数据学习通用表示，使同一个预训练模型能够用于多种无机材料的能量、力、应力和动力学预测 [4–6]。其中，MACE-MP-0 基于 MACE 架构和大规模无机晶体轨迹训练，展示了跨固体、液体、界面乃至分子体系的零样本能力，并可作为下游势模型的初始化 [5]。这种“基础势 + 下游适配”的范式能够复用昂贵的预训练知识，降低为每种材料重新收集数据和从头训练模型的成本。

然而，通用性并不等于在任意目标体系上都达到所需精度。预训练数据在元素组成、结构类型、能量范围和构型采样密度上高度不均衡，且往往以弛豫轨迹和近基态构型为主。已有研究发现，M3GNet、CHGNet 和 MACE-MP-0 等通用势在表面、缺陷、迁移势垒、声子和高能构型上可能系统性低估能量变化与力，即出现势能面“软化”；这种系统误差可以用少量目标数据显著校正 [7]。因此，对基础势进行小样本微调不是预训练失败后的补救，而是把广域先验转化为特定精度势模型的必要环节。

## 2. 参数高效微调：应当更新多少，以及如何更新

最直接的适配方法是更新全部参数，但小规模下游数据不足以约束一个大型等变网络的所有自由度。全参数微调可能过拟合目标数据、破坏预训练表示，或者在有限算力下难以完成充分优化。与之相对，冻结底层表示、只更新读出层或尾部交互层，可以降低可训练参数量并保留通用知识。Radova 等人的冻结迁移学习研究表明，在表面反应和三元合金任务中，部分冻结的 MACE 基础势使用约 10%–20% 的目标数据即可达到接近从头训练模型的精度 [8]。这说明“解冻多深”本身就是影响样本效率和性能上限的重要变量，而不是一个纯粹的工程选择。

低秩适配（low-rank adaptation, LoRA）提供了另一条路径：冻结预训练权重，只学习低秩增量，从而用更少的参数表达任务相关修正 [9]。但普通 LoRA 不能不加区分地应用于等变网络。等变层中的权重与不可约表示、张量积路径和奇偶性相联系，任意矩阵低秩化可能破坏模型的旋转等变结构。ELoRA 为此提出按等变张量积路径进行低秩分解，在冻结预训练权重的同时保持 \(SO(3)\) 等变，并在 rMD17 和多个无机数据集上展示了优于全参数微调的能量与力误差 [10]。

ELoRA 解决了“如何以低秩方式更新等变权重”的问题，却仍默认所有下游样本共享同一组适配参数。对于包含多种晶体结构域的数据，这一假设未必总是最优：不同组成、局部配位、结构原型和热扰动范围可能要求方向不同甚至相互冲突的参数修正。一个共享 adapter 可以利用全部数据，但也可能在异质结构域之间产生负迁移；为每个材料分别建立 adapter 能避免部分冲突，却会导致数据碎片化、存储增长和对新材料缺乏共享。由此产生本课题的核心问题：能否在“完全共享”与“每种材料独立建模”之间找到具有物理含义、参数成本可控的中间划分？

## 3. 为什么考察晶体学条件专家

周期晶体天然带有层级化的晶体学标签。晶系描述较粗粒度的晶胞与对称关系，点群描述忽略平移后的点对称操作，空间群进一步包含平移、螺旋轴和滑移面等信息。它们不能决定材料的全部化学与局部相互作用，却提供了一种无需额外监督学习即可获得的结构域描述。与“一个材料一个专家”相比，晶体学标签有机会让多个组成和结构原型共享同一组增量参数；与完全共享的微调相比，它又允许不同结构域对预训练模型进行差异化修正。

这里必须区分两类完全不同的对称性。MACE 的 \(E(3)\) 等变性描述的是坐标系整体旋转、反射和平移时，能量和力应当如何变换；晶系、点群和空间群描述的是理想周期结构本身的内部对称关系。本课题不会用空间群去“修复”MACE 的几何等变性，也不会把热扰动构型的力投影到母相对称子空间。晶体学标签仅作为结构域条件，用来选择一组保持等变的参数增量：

\[
W_g=W_0+\Delta W_g,
\]

其中 \(W_0\) 是共享的预训练权重，\(\Delta W_g\) 是第 \(g\) 个结构域的 Dense 或 ELoRA 增量。所有专家复用同一份基础权重，从而把专家化限制在下游修正，而不是复制多个完整 MACE 模型。

这种设计可以被看作晶体学条件化的 mixture-of-experts（MoE）。MoE 通过路由器只激活部分专家，使模型容量与单次计算成本部分解耦；但在原子势中，路由还必须满足能量守恒、几何等变、原胞/超胞一致性和动力学连续性。2026 年关于 MLIP-MoE 的系统研究发现，共享专家与稀疏专家结合可以提升大规模原子势的精度，但元素级路由整体优于构型级路由，而且全局构型路由可能导致数值不稳定 [11]。这一结果既支持“专家化可以缓解异质数据冲突”，也直接提醒我们：晶体级硬路由不能被默认视为有效方案，而必须与共享模型、学习路由和非晶体学分组进行严格比较，并检查专家切换处的能量与力行为。

晶体学路由还存在一个基础性的适用边界。若使用弛豫母相的空间群为整条扰动轨迹选择专家，模型严格来说学习的是条件势能 \(E(x,g_{\mathrm{parent}})\)，而不只是当前构型 \(x\) 的函数。因此，主实验首先面向母相已知、相内扰动且标签固定的周期晶体；它不预设该方法可以直接处理跨相变轨迹、未知结构、缺陷形成或任意高温重构。对于可学习的软路由，力必须由包含路由权重在内的总能量完整求导；对于 top-1 硬路由，还需额外检验路由边界上的能量和力连续性。明确这一边界，可以避免把“结构域条件提高统计效率”误述为“施加了新的物理对称约束”。

## 4. 从势能面扩展到标量、张量与频率依赖性质

以能量—力联合学习作为第一个 benchmark，并不意味着课题最终局限于原子势。恰恰相反，能量和力提供了检验适配方法的最严格起点：能量必须保持旋转、反射和平移不变，力必须随坐标等变，且二者还要满足 \(\mathbf F_i=-\partial E/\partial \mathbf r_i\) 的微分一致性。只有先确认 Dense、ELoRA 和专家路由不会破坏这些基本性质，才有理由把同一套“共享等变骨干 + 结构域参数增量”推广到其他材料任务。

第一类扩展是标量性质。形成能、带隙、磁矩大小、转变温度等目标在整体旋转下保持不变，可由骨干中的标量通道和任务特异 readout 预测。早期晶体图网络已经证明，结构图表示可以用于形成能、带隙等多种标量性质 [12]。但这些任务不能被简单等同于势能学习：总能量通常要求尺寸广延性，带隙等性质则通常是强度量；带隙也不是势能对结构变量的导数。因此，扩展时可以复用等变表示和专家参数化，却必须重新设计池化、输出头、损失函数和数据切分。

第二类扩展是张量性质。二阶介电张量、四阶弹性张量和三阶压电张量在坐标旋转下不能保持逐分量不变，而应按照相应张量表示变换，同时满足指标置换、反演和晶体点群带来的零分量或分量相等关系。MatTen、一般晶体张量等变网络和 EATGNN 已分别证明，可将弹性、介电和压电张量分解到球谐不可约表示中，由等变网络直接预测完整张量，而不是在固定坐标系中独立回归各个分量 [13–15]。对于这类任务，晶体学专家可能比在标量任务中更有意义，因为点群不仅与数据分布相关，还直接决定允许出现的张量子空间。不过，硬路由标签仍然只是条件信息；输出张量本身的协变规律应由等变输出头保证，不能依靠专家标签事后修正。

第三类扩展是频率依赖性质，例如复介电函数、光学电导、吸收谱、声子态密度以及频率依赖的各向异性响应。此时目标可以写成标量或张量值函数 \(Y(\omega)\)，模型既要处理频率轴上的连续结构，又要在每个 \(\omega\) 上满足正确的空间变换规律。TSENN 已展示从晶体结构直接预测完整频率依赖介电张量的可行性，并利用 Kramers–Kronig 关系从虚部重建实部 [16]。这说明等变表示能够从静态张量推广到张量谱，但新的物理约束也随之出现，包括因果性、实部与虚部的一致性、谱线展宽、频率分辨率和求和规则。因而，频率可以作为连续条件输入或由谱基展开表示，晶体学专家则负责结构域适配；两者不应混为同一种路由维度。

从方法上看，这些任务可以共享一个统一框架：预训练等变骨干提供结构表示，任务头规定输出的物理类型，ELoRA 或 Dense 增量完成下游适配，晶体学或学习路由决定激活哪组增量参数。统一的是参数共享、等变适配和结构域划分问题；不统一的是标签生成方法、输出表示、物理约束和评价指标。因此，本课题采取“先验证方法内核，再扩展性质类型”的路线，而不是从一开始把所有性质混入同一个 benchmark。

## 5. 现有工作的空缺

现有文献已经分别回答了四个相邻问题：等变原子势证明了几何归纳偏置能够提高势能与力的学习效率 [1–3]；晶体图网络和等变张量模型证明了结构表示可以覆盖标量、张量和张量谱等不同目标 [12–16]；基础势和冻结迁移学习证明了广域预训练知识可以用少量目标数据适配到专门体系 [5,8]；ELoRA 和 MLIP-MoE 则分别展示了等变低秩更新与稀疏专家化的可行性 [10,11]。但这些方向之间仍存在一个未被系统回答的交叉问题：在保持输出物理变换规律的前提下，晶体学结构域能否成为比共享 adapter、随机分区或一般学习路由更有效的参数高效微调单位，而且这种收益能否从势能—力任务迁移到标量、张量和频率依赖性质？

这个问题不能通过“空间群专家优于一个共享模型”这一项比较回答。空间群与组成、结构原型、密度、原子数和能量分布高度相关，模型可能只是在利用材料身份或数据集偏差。空间群数量增加还会同时增加总参数量，使表面上的精度提升来自额外容量而非晶体学信息。预训练数据与下游数据的重合也可能把记忆误认为迁移。因此，有说服力的证据至少需要满足四个条件：

1. 在相同解冻范围和参数预算下比较 Dense 与 ELoRA，并报告总参数、可训练参数、单样本激活参数、显存和训练时间；
2. 将真实晶系、点群和空间群路由与 Shared、等频随机标签、组成或结构原型分组以及 Learned-\(K\) 路由比较；
3. 按独立母结构或轨迹分组切分，并在组成控制、化学体系不相交和预训练新颖子集上验证增益；
4. 同时检查能量误差、力误差、等变误差、势能连续性和短程动力学稳定性，避免把类别能量偏置或标签泄漏解释为更好的原子势。

## 6. 本课题的问题与预期贡献

基于上述背景，本课题研究的是**面向等变材料模型的结构域参数高效适配**。第一阶段以 MACE-MP 基础势和有限标注数据下的能量—力联合微调为主任务，并沿三个彼此关联的维度展开：第一，比较只更新逐层能量 readout、尾部若干交互层、除首层外的大部分网络和全模型更新，确定解冻深度与数据规模之间的关系；第二，在相同更新范围内比较 Dense 更新与 ELoRA，区分原生配置和参数预算匹配配置；第三，比较 Shared、晶系、点群、空间群和 Learned-\(K\) 专家，检验显式晶体学标签是否提供超越组成与材料身份的增量信息。

在第一阶段建立可靠结论后，后续工作将逐级扩展输出空间：先考察带隙、形成能等旋转不变标量，再考察介电、弹性、压电等协变张量，最后考察介电谱、光学电导等频率依赖的标量或张量响应。每一级扩展都重新定义任务头与物理一致性测试，但保留相同的核心比较：共享适配是否受到结构域负迁移，晶体学专家是否优于等容量的随机、组成或学习分区，以及 ELoRA 是否能以更低参数成本保持目标输出的正确变换规律。

本课题不预设空间群专家一定优于共享微调。更可检验的假设是：当每个结构域的数据少到不足以独立训练完整模型、但又足以估计小型参数增量时，结构域专家可能减少共享 adapter 中的负迁移；在极小数据下，专家化可能因样本进一步分散而变差；在数据充分时，共享模型和专家模型都趋于饱和，专家的相对收益可能缩小。由此，真正需要刻画的不是单个数据点上的排名，而是专家收益随“每专家有效独立结构数”变化的学习曲线。

预期贡献包括：

1. 建立 MACE 基础势在不同解冻深度下的系统微调基线，并给出精度、样本量和计算成本之间的关系；
2. 明确 ELoRA 与直接梯度更新在不同数据规模和参数预算下的适用区间；
3. 在严格控制组成、原型、参数量、数据泄漏和预训练重合后，判断晶体学标签能否作为有效的结构域条件；
4. 比较显式晶体学路由与可学习路由，分析专家利用率、路由塌缩及其与组成和晶体标签的关系；
5. 给出晶体级专家用于保守原子势的适用边界，包括等变性、势能单值性、路由连续性和部署时标签可得性；
6. 建立从标量、向量到高阶张量和频率依赖响应的扩展协议，明确哪些骨干与适配参数可以共享，哪些输出头、损失和物理约束必须针对任务重新设计。

如果真实晶体学路由在预算匹配、母结构不相交和组成控制的测试中仍稳定优于 Shared 与随机/非晶体学分区，便说明晶体学结构域可以为等变基础势提供有用的下游条件先验；如果 Learned-\(K\) 更优，则说明最有利的统计结构域并不等同于传统晶体学分类；如果所有专家方案均不优于 Shared，则意味着预训练 MACE 的共享表示已经足够，或当前数据无法把对称信息与材料身份分离。无论哪种结果，都能把“何时应当共享、何时应当专业化”从经验选择转化为可检验的微调规律。

更长远地说，课题希望回答的不是某一种势模型上的单点性能问题，而是一个跨性质类型的问题：当材料任务共享几何表示、却具有不同输出对称性和物理约束时，结构域专家能否成为连接通用预训练与专门性质预测的可复用适配机制。

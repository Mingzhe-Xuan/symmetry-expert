# 对 `plan_v0.md` 的检索评议

## 总体结论

**原始版本需要大修后才适合作为开题依据；修订后的命题具有可执行性，但应定位为经验性假设，而不是由 Neumann 原理直接推出的结论。**

值得保留的研究问题是：在严格保持 O(3)/E(3) 等变的底座上，引入点群或空间群条件化的轻量专家，是否能提高晶体性质预测的数据效率、长尾类别表现或精度。这个问题可证伪、能构造参数匹配基线，也有明确工程路径。不能保留的核心论证是“O(3) 覆盖范围太宽，所以不够精确，按晶体对称性训练专家会得到更精确的等变性”。两类对称性作用不同，后者不是前者的简单替代。

## 命题核查

| 原命题 | 判断 | 依据与修正 |
|---|---|---|
| 晶体区别于分子/蛋白的关键特征是周期性边界条件 | 基本正确，但不充分 | 周期性是经典三维晶体的核心特征；晶体还涉及晶格、基元和空间群，且广义晶体定义还包含非周期晶体。开题聚焦周期晶体即可，但应明确范围 [1,2]。 |
| “组分 + 对称性”唯一确定晶体结构 | 错误 | 相同组分和空间群可对应不同晶格常数、Wyckoff 占位、自由坐标或多晶型。必须加入晶格和原子位置/占位 [1,2]。 |
| Neumann 原理要求物性与晶体具有“相同”对称性 | 表述过强 | 原理要求物性张量在晶体点群操作下不变，物性张量的对称群可以比晶体点群更大，而非必须恰好相同 [3]。宏观张量通常看点群；能带需讨论倒空间和小群，不能一概而论。 |
| O(3)/SO(3) 等变“覆盖所有空间群” | 不准确 | O(3) 只含绕原点的正交变换；空间群还含晶格平移、螺旋和滑移。周期图、平移处理和原子置换共同参与后，O(3) 等变模型才可能对结构的空间群操作给出一致结果 [6]。 |
| O(3) 等变太宽泛，会使晶体表示不够精确 | 缺少理论依据，且易混淆 | 整体任意旋转下的协变是坐标无关性的要求，不意味着预测各向同性。对具体晶体稳定子群的约束可由严格等变性与结构不变性推出。显式 symmetry token/专家可能改善统计效率，但必须由对照实验验证，不能从群大小直接推出 [6]。 |
| local frame 在高对称结构上会有非唯一性 | 有条件成立 | 单一规范化 frame 在退化或高对称输入上确有歧义/不连续风险 [10]；但 frame averaging 和完备局部 frame 是不同路线 [8,9]，原稿“直接取自蛋白表示”的概括没有依据。 |
| 球谐高阶特征和 CG tensor product 计算昂贵 | 基本正确 | 完整张量积随最高阶数增长很快；eSCN 等已有严格等价的降复杂度方案，因此应描述为已被持续优化的瓶颈，而不是未解决的统一缺陷 [7]。 |
| 普通 LoRA/full fine-tuning 可直接用于等变后半层 | LoRA 部分存在关键风险 | 任意低秩矩阵或 adapter 会混合不兼容的 irrep，破坏等变性。应使用 irrep 分块的等变 LoRA、等变线性层或标量幅值门控 [15]。全量微调只有在架构本身约束参数化时才继续保持等变。 |
| adapter 参数彼此接近 + 同 decoder 可保证输出在同一空间 | 不成立 | 参数距离与表示对齐没有这种保证。可验证条件应是专家输出具有完全一致的 irrep 类型和变换律，且通过等变测试；若还要求跨专家语义对齐，可增加蒸馏、共享投影或表示对齐损失。 |

## 开题合理性与创新性

### 合理之处

1. 以预训练等变模型为底座，仅适配后层，计算成本可控；对长尾类别采用共享主干和小型残差专家也符合数据规模约束。
2. 对称性信息确实可能提供额外统计先验。SEN、CrysMMNet、GMTNet 和 CLOUD 分别从等价原子、额外模态、空间群一致张量和 Wyckoff/生成元编码等角度给出了正面证据 [6,11–13]。
3. 方案能够提出清晰的反事实基线：真实对称类别对比随机分组、对称标签、单 adapter 和参数匹配专家。只要预注册判定标准，结果无论正负都有解释价值。

### 主要问题

1. **原始理论动机不成立。** 连续坐标变换等变与结构内禀对称不能用“宽泛/精确”排序。建议以“条件化归纳偏置和参数高效适配”重建动机。
2. **创新空间已明显收窄。** GMTNet 已直接研究 O(3) 与空间群一致的晶体张量预测 [6]；SEN 和 CrysMMNet 已显式利用对称信息 [11,12]；2026 年已有严格等变 adapter [15]，PRISM 也已把不同晶体表征模块组织为 MoE [16]。PRISM 的专家并非按对称类别路由，故未完全覆盖本课题，但潜在创新必须是这些要素的特定结合——层级对称路由、严格等变 PEFT、长尾评估——而不是其中任一单项。
3. **按 230 个空间群拆专家很可能数据不足。** 空间群分布高度不平衡，且宏观张量的零元和等值约束主要由 32 个点群决定。点群应为主方案，空间群作为消融；必要时采用晶系→点群→空间群的层级残差。
4. **“先判断对称性”的设定含潜在泄漏和部署落差。** 数据库空间群标签通常由完整结构经容差判定得到。如果测试输入已含精确结构，路由可视为已知元数据；若实际输入不含可靠标签，则应报告预测路由误差和对下游性质的传播。
5. **任务选择决定命题是否有意义。** 对介电、压电、弹性等张量，点群给出直接可测的输出约束；对形成能、带隙等标量没有额外分量约束。若资源有限，应优先做一个张量任务，并用标量任务检验收益能否外推。
6. **共享 decoder 不自动解决专家空间对齐。** 架构需先保证相同 irrep schema；正则应约束函数或表示，而不仅是参数欧氏距离。

## 建议的最小可行开题

将问题收缩为：**在同一周期 O(3) 等变底座和参数预算下，按晶体点群路由的 irrep-preserving adapter，能否优于单 adapter、symmetry embedding 和随机路由，并在不增加等变/Neumann 违反率的情况下改善张量性质预测？**

第一阶段只比较 7 个晶系专家与 32 个点群专家，避免直接训练 230 个独立空间群专家。使用一个张量数据集，固定底座、decoder、总可训练参数和训练步数；报告 micro/macro MAE、每类置信区间、等变误差、点群投影残差和吞吐。只有真实路由稳定超过随机路由及 symmetry-token，才能把收益归因于对称性条件化，而不是参数增加。第二阶段再加入标量任务、空间群层级和预测路由。

## 最终评价

- **命题正确性（原稿）：** 较弱。存在一个事实错误、两个群论概念混淆，以及 LoRA 可能破坏等变性的未处理风险。
- **研究价值（修订后）：** 中等偏高。问题具体、可证伪，与晶体张量预测及等变基础模型适配相关。
- **创新性：** 中等。需要以严格对照证明“对称路由”本身的作用；仅仅建立多个专家不足以区别于已有显式对称模型。
- **可行性：** 中等。32 点群层级 adapter 可行；230 个独立专家在常见数据规模下风险高。
- **建议：** 有条件通过开题。通过条件是采用修订后的理论表述、明确任务和数据分布、改用严格等变 adapter，并加入参数匹配与随机路由基线。

本评议基于截至 2026-08-31 的公开网页、论文主页与出版物检索；它能判断当前论证是否得到主要相关工作支持，但不等同于系统综述或专利新颖性检索。引用编号沿用 `plan_v0.md` 的参考文献表。
